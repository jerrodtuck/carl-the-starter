# Bake 001 — Carl.1

**Mixed:** 2026-09-06 · **Baked:** 2026-09-07

| Variable | Value |
|----------|-------|
| Formula | 500 flour / **360** water / 100 Carl / 10 salt |
| True hydration | ~77% (135% starter accounted) |
| Dough temp after mix | **83.6°F** (target 76–78) |
| Bulk | ~2h 5m; mark reset after fold 1 (misleading) |
| Folds | 4 |
| Retard | ~9.5 hr |
| Bake | 450 covered 20 / 425 uncovered ~25; pull **207°F** |
| Result | Strong ear; moderately open set crumb; not overproofed |

## Lesson

Hot dough + moved mark caused a false "past double." Ear proved gas in reserve. Next: never move the mark; record water temp; stay ≤82°F unattended.
